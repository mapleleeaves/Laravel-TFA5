# POS Application

A simple Laravel application with four pages:

- Home
- About
- Customer Accounts
- User Accounts

The customer and user pages display sample records from static PHP arrays.

## How to run

1. Install the project dependencies with `composer install`.
2. Copy `.env.example` and rename the copy to `.env`.
3. Run `php artisan key:generate`.
4. Start the development server with `php artisan serve`.
5. Open the local address shown in the terminal.
